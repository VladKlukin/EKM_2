# Задача «Почтальон» (Дуб в Лукоморье)

Консольное приложение на C++, решающее задачу оптимизации маршрута почтальона (Мудрого тритона) на графе-дереве с минимальным количеством извинений перед жителями (птицами).

## 📝 Описание задачи

Мудрый тритон работает почтальоном в Лукоморье. Ему необходимо доставить корреспонденцию птицам, чьи гнезда расположены на развилках дуба. Дуб представляет собой связный ациклический граф (дерево) с корнем в гнезде №1. 

Если путь тритона проходит через чье-то гнездо, а его обитатели в этот момент не получают писем (потому что писем для них нет, или их уже отдали ранее), интеллигентный тритон обязан принести **извинение**. Программа рассчитывает оптимальный маршрут, минимизирующий суммарное количество извинений.

### Алгоритм оптимизации:
1. **Фильтрация дерева (DFS):** Программа обходит граф и помечает только те поддеревья, в которых есть хотя бы одно письмо. Пустые ветки полностью игнорируются, тритон туда не заходит.
2. **Жадный обход:** При ветвлении тритон сначала обходит более короткие «боковые» ветви (с возвратом и извинением), а самую глубокую ветвь оставляет на финал маршрута, чтобы уйти по ней без необходимости возвращаться назад.

## 🚀 Особенности реализации (Features)

* **Собственные динамические структуры данных:** Проект написан без использования STL-контейнеров (vector, list). Реализован собственный динамический односвязный список `List` и структура управления деревом `Tree`.
* **Надежная валидация (Анти-краш):** Класс `Validator` защищает программу от некорректного ввода (ввод букв вместо чисел, отрицательные значения) и проверяет граф на структурную связность перед запуском алгоритма.
* **Интерактивный интерфейс:** Поддержка 3 режимов ввода данных (клавиатура, загрузка из `.txt` файла, автоматическая случайная генерация дерева для стресс-тестов).
* **Визуализация графа:** Функция `printTree()` отрисовывает текущую структуру дуба в консоли в виде дерева с отступами.
* **Пошаговая трассировка:** Метод `traceRoute()` детально расписывает каждый шаг тритона: куда он зашел, когда отдал письма и где извинился.

## 📂 Структура проекта

* `Node.h` / `Node.cpp` — Элемент динамического списка.
* `List.h` / `List.cpp` — Собственный класс односвязного списка (замена `std::vector`).
* `Tree.h` / `Tree.cpp` — Логика хранения дерева вершин (`Vertex`), обхода в глубину (DFS) и симуляции маршрута.
* `Validator.h` / `Validator.cpp` — Логика проверки корректности данных, связности графа и очистки буфера ввода.
* `Menu.h` / `Menu.cpp` — Консольное меню управления приложением.
* `main.cpp` — Точка входа в программу.
